# 深度理解导师（deep-understanding-tutor）

## 这是什么？

一个基于认知科学的 AI 学习辅助 Skill。它的核心差异在于：

**普通的 AI 学习助手是「老师」——告诉你答案。**
**这个 Skill 是「教练」——引导你自己找到答案。**

灵感来源于：
- KELE 框架（EMNLP 2025）—— 多 Agent 苏格拉底教学
- SocraticLM（NeurIPS 2024 Spotlight）—— 步骤级思维引导
- 费曼技巧（Feynman Technique）—— 以教促学的验证方法
- AI 教育认知悖论（Frontiers in Psychology, 2025）—— 脚手架 vs 替代品

## 核心工作方式

### 传统模式 vs 本 Skill

| | 传统 AI 助手 | deep-understanding-tutor |
|--|-------------|------------------------|
| 你问 "什么是 XX？" | AI 直接给出完整定义和解释 | AI 先问 "你对 XX 有了解吗？" |
| 你答不上来 | AI 直接给答案 | AI 给提示（hint），引导你自己想 |
| 你理解有偏差 | AI 说"不对，正确答案是..." | AI 用反例让你自己发现矛盾 |
| 学完之后 | 结束 | 要求你用自己的话解释一遍（费曼验证） |

### 苏格拉底五阶段对话流

每次学习一个概念，AI 会引导你经历五个阶段：

```
① 唤醒前知 → "你对 XX 有了解吗？"
② 引导发现 → "你觉得需要什么？为什么？"
③ 暴露冲突 → "如果条件变了，还成立吗？"
④ 协助建构 → "我们整理一下..."
⑤ 翻转验证 → "你向朋友解释一下 XX？"
```

**阶段 ⑤ 不会跳过**——这是确认你是否真正理解的门禁。

## 什么时候用它？

### 适合的场景

- 想要**深度理解**一个概念，而不只是记住定义
- 学过的东西总觉得"看懂了但不会用"
- 希望学习过程有**可追溯的记录**（Git-friendly）
- 任何领域都可以：技术概念、数学原理、业务知识等

### 不适合的场景

- 只需要一个快速的定义或事实查询（用普通 AI 回答更快）
- 时间极其紧迫，只需要一个答案而不是理解
- 已经精通某领域，只需要查漏补缺

### 触发方式

在对话中说以下任意一句即可激活：

- "我想从零开始理解 XX"
- "帮我深入搞懂 XX"
- "@deep-understanding-tutor 学习 XX"
- "用苏格拉底的方式带我学 XX"

## 使用示例

### 示例 1：学习一个全新的技术概念

```
你：@deep-understanding-tutor 我想学习 "RPC"

AI：你对 RPC 有了解吗？在什么场景下听说过？

你：不太清楚，好像跟网络调用有关

AI：没错，和网络调用有关！想象一下——你在你的电脑上想调用另一台
   机器上的一个函数，就像调用本地函数一样。你觉得要做到这件事，
   需要解决哪些问题？

你：嗯...需要知道对方地址？还需要约定数据格式？

AI：很好的起点！地址和格式确实是两个核心问题。那我再问你——
   为什么不能直接用 HTTP 调用呢？HTTP 也能传数据啊。

你：HTTP...好像比较重？

AI：你直觉很准！[展开讲解...] ...现在我们整理一下刚才讨论的要点...

   ...（多轮对话后）...

AI：好了！现在假设你要向你一个不懂技术的朋友解释 RPC，
   你会怎么说？要求：用一个生活类比，不说专业术语

你：RPC 就像在餐厅点菜——你是顾客（客户端），厨房是服务端，
   你不需要知道菜怎么做，只需要把菜单（协议）传过去，
   厨房做好后把结果端给你...

AI：这个类比很棒！核心抓住了。补充一个小细节...
   要我把今天的内容整理成一张知识卡片吗？
```

### 示例 2：当你赶时间时

```
你：@deep-understanding-tutor 请直接告诉我什么是 "容器化"

AI：好的，那我直接来讲。[完整讲解...]

   以上就是容器化的完整解释。现在——虽然是我讲的——
   但我还是想请你做一件事：用你自己的话给朋友介绍一下容器化？
   这样我能确认你真的理解了，而不只是"看懂了"。

你：容器化就像...把应用和它需要的所有东西打包到一个箱子里，
   不管搬到哪台机器上都能一样运行...

AI：非常好的解释！你理解了核心。补充一点...
```

## 会产生什么？

学习过程中/结束后，Skill 可以生成以下**学习产物**（Markdown 文件）：

| 产物 | 内容 | 用途 |
|------|------|------|
| 知识卡片 | 核心定义、直觉类比、关键要点、常见误区 | 快速复习 |
| 费曼输出记录 | 你的解释原文 + AI 诊断 | 追踪理解成长轨迹 |
| 对话摘要 | 完整问答轨迹、关键洞察 | 回顾学习过程 |
| 复习提醒 | T+1/T+3/T+7/T+30 复习计划 | 对抗遗忘曲线 |

所有产物都是**个性化**的——基于你在对话中的真实表现生成，而非通用模板填充。

## 与 deep-learning-assistant 的关系

`deep-learning-assistant` 是本 Skill 的**前身和灵感来源**。

| 维度 | deep-learning-assistant | deep-understanding-tutor |
|------|------------------------|--------------------------|
| 定位 | 深度学习领域的知识讲授器 | 通用领域的苏格拉底教练 |
| 核心模式 | AI 讲 → 用户听 | AI 问 → 用户想 → AI 引导 |
| 领域绑定 | 深度学习专用 | 领域无关 |
| 交互形态 | 主要生成文档 | 主要多轮对话 + 文档为辅 |

本 Skill 继承了 deep-learning-assistant 的优秀讲解能力（作为 L2 后备），
但将核心交互模式从「讲授」升级为「引导」。

## 理论基础

本 Skill 的设计基于以下经过实证验证的认知科学研究：

| 来源 | 核心贡献 |
|------|---------|
| Jose et al., Frontiers in Psychology, 2025 | AI 教育认知悖论：脚手架 vs 替代品 |
| KELE, EMNLP 2025 | 苏格拉底 SocRule 五阶段，34 种教学策略 |
| SocraticLM, NeurIPS 2024 Spotlight | 步骤级思维引导，三 Agent 架构 |
| Dunlosky et al., 2013 | 六大学习技术有效性评测 |
| Bloom-Anderson 分类学 (2001) | 认知六层次：从记忆到创造 |
| Feynman Technique | 以教促学：暴露盲区的最佳方法 |
